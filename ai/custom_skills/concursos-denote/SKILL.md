# Denote notes — reading and reuse (read-only)

## 1. Convention
- File names carry a hierarchical signature:
  =20261001T082645==28g--conceito-de-passivo...=.
- ==28= is the root; ==28g=, ==28k1= are descendants.

## 2. Search
- Signature given by the student (e.g. ==28=): use Glob with `*==28*` to find
  the root + descendants.
- No signature: use Grep with keywords of the topic.
- Read the relevant notes in one pass; avoid re-reading the same file.

## 3. Reuse (the student's "voice")
- Reuse CORRECT excerpts from the notes in the explanation/deepening, WITHOUT
  citing the note as a source. The text should sound like the student's own
  notes.
- Legal citations/foundations remain MANDATORY — reuse does not replace the
  accuracy verification (skill =concursos-acuracia=).
- If there is no relevant note, proceed normally.

## 4. Limit (read-only)
- You NEVER create, edit, or rename notes. If a note/suggestion would be
  useful, SUGGEST it to the student (title/subject + why); they decide.
